# Design Patterns in C#

🚀 A collection of **Creational, Structural, and Behavioral** design patterns implemented in **C#** with concise explanations and code examples.

## 📌 Design Patterns Covered

### ✅ Creational Design Patterns
- **Singleton** – Ensures a class has only one instance.
- **Factory** – Creates objects without specifying their exact class.
- **Abstract Factory** – Provides an interface for creating families of related objects.
- **Builder** – Separates object construction from its representation.
- **Prototype** – Creates new objects by copying an existing object (if time permits).

### ✅ Structural Design Patterns
- **Adapter** – Allows incompatible interfaces to work together.
- **Bridge** – Decouples abstraction from implementation.

### ✅ Behavioral Design Patterns
- **One-to-Many** – Establishes a relationship where one object updates multiple objects.
- **Observer** – Defines a one-to-many dependency between objects.
- **Strategy** – Enables selecting an algorithm at runtime.

## 🚀 Getting Started

1. **Clone the repository**
   ```sh
   git clone https://github.com/yourusername/DesignPatterns.git
   cd DesignPatterns
   ```
2. **Open in Visual Studio/VS Code**
3. **Run the specific design pattern**
   ```sh
   dotnet run
   ```
